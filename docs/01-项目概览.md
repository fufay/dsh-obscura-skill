# 01 · 项目概览（dsh-obscura-skill）

## 目标

把 **Obscura**（<https://github.com/h4ckf0r0day/obscura>，Rust 无头浏览器，真渲染）封装成**跨平台 DSH skill**，
作为 `dsh-lightpanda` 的"增强后端"：**比 lightpanda 功能更全**——真实渲染截图 / PDF、cookie 持久化、
assets 与 HttpOnly cookie 导出、Windows 原生、MCP；覆盖 HarmonyOS PC / Linux / macOS / Windows。

## 范围（要做什么）

- [x] `skill/dsh-obscura/`：SKILL.md + `scripts/{resolve,fetch,serve,cdp}.mjs` + `assets/manifest.json`。
- [x] 资产：上游 v0.2.7 render 版（Linux/macOS/Windows）+ **本项目自建 OHOS musl 版**（`tools/build-obscura-ohos.sh`）。
- [x] 三档能力：P2 fetch（markdown/html/text/links/assets/cookies/original）、P4 渲染（截图/PDF）、P3 serve+CDP。
- [x] 发布工具：`tools/publish-release.sh`（GitHub + AtomGit）、`tools/atomgit_release.py`。
- [x] 文档：资产清单、发布流程、与 lightpanda 的能力对比。

## 明确不做（边界）

- 首版**不含 stealth**（BoringSSL/TLS 指纹）——上游 stealth 资产存在，但 OHOS 自建暂未编 stealth；
  需要强反爬再单独立项（见 `docs/10` 风险）。
- 不改 Obscura 源码；不编 V8 源码（用官方 musl 预编译归档）。
- 不做验证码识别/视频播放/真实浏览器 UI 流程（这类交用户或其它工具）。
- 不在仓库里存二进制（全部走 release 资产 + sha256 + 缓存）。

## 关键约束

- Node ≥18；`cdp.mjs` 需要 Node 22+（内建 `WebSocket`）。
- OHOS：**`/tmp` 不可执行**（EPERM），缓存必须放 `$HOME`/项目内；二进制需自签（资产里已签）。
- 上游 release 只有 glibc/macOS/Windows；**OHOS musl 资产由本项目维护**。
- 网络：GitHub/上游走按需代理；大文件下载默认走 `resolve.mjs` 的多镜像回退。

## 验收标准

- `resolve.mjs --check` 选对资产；`--path`（默认输出）下载+sha256 校验+解压。
- `fetch.mjs` 三种 dump（markdown/text/html）+ `--screenshot` 跑通。
- `serve.mjs ensure` + `cdp.mjs --screenshot/--pdf` 跑通，CJK 正常（OHOS 自动挂 `/system/fonts`）。
- 无网络环境下 `DSH_OBSCURA_LOCAL_DIR` 可安装。
